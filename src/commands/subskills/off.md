# agit off

## Purpose

Stop automatic saving and uploading for a folder that `agit on` (or `agit save`) turned on.
Saved sessions stay on this computer and on the Hub. `agit on` turns it back on.

## Synopsis

```bash
agit off [DIR]
```

## Examples

```bash
agit off
agit off --json
```
