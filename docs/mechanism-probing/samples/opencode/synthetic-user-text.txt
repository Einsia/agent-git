# OpenCode injected (synthetic) user text: the inventory and the test

The test is simple: the text part carries "synthetic":true (which reads out of SQLite JSON as 1).
Of the 496 user text parts in the whole database, 105 are synthetic and 391 are human.

## Shape summary (merged by hand)

- `Called the <Tool> tool with the following input: {…}` (86, counted exactly by `LIKE 'Called the % tool with the following input%'`) — the synthetic user
  message generated when a tool call is rewritten as plain text for a channel that does not support tool-use.
- `<system-reminder>Note: The user opened the file "…" / selected #N …` (11) — IDE context reminder.
- `Continue if you have next steps, …` (4) — the continuation injected after a compaction or an
  interruption; the part also carries `metadata.compaction_continue` (see compaction-anatomy.txt).
- `[SYSTEM DIRECTIVE: OH-MY-OPENCODE - TODO CONTINUATION] …` — the omo plugin's todo continuation injection.
- `The previous request exceeded the provider's size limit due to large media attachments. …` (1)
  — notice of a retry after media went over the size limit and was compressed.

Text parts on the assistant side never carry synthetic (all 1426 are empty).
Another 6 text parts carry `metadata.compaction_continue` (the first 4 are the Continue injections
above, all synthetic=1; one has host agent "Sisyphus - ultraworker" and a SYSTEM DIRECTIVE body).
