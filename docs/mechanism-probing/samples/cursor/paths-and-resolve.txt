# Cursor transcript paths and resolve cost — measured on this machine (105 transcript files / 77 project slugs)

## Path templates
main session:  ~/.cursor/projects/<project-slug>/agent-transcripts/<session-uuid>/<session-uuid>.jsonl
subagent:      ~/.cursor/projects/<project-slug>/agent-transcripts/<parent-uuid>/subagents/<sub-uuid>.jsonl

## project-slug rule (measured across 10+ samples)
slug = every non-ASCII-alphanumeric character in cwd becomes '-', then the leading '-' is stripped
  /Users/nana/Projects/AgentGit                     -> Users-nana-Projects-AgentGit
  /mnt/data/shared/homes/...                       -> mnt-data-shared-homes-...
  demo-app.orig                                    -> ...-demo-app-orig
i.e. domain::store::slug_for(cwd).trim_start_matches('-')
   (Claude Code uses the variant that keeps the leading '-')
